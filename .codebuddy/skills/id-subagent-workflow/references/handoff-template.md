# 任务交接模板

复制正文到 `docs/handoffs/<task-id>.md`，替换占位内容。简单任务直接使用相同字段的简短委派消息，不必建文件。主 Agent 在派发前填写；SubAgent 完成后只更新获准的结果区，再由主 Agent验收。空字段明确写“无/未决定”，不要猜测。

## 元信息

- 任务编号：<唯一编号>
- 状态：draft / ready / in_progress / blocked / completed
- 执行 Agent：<注册名称>
- 执行模式：只读评审 / 制定计划 / 实施代码
- 日期与源码基线：<日期、提交、未提交修改摘要>

## 共享摘要（主 Agent 与 SubAgent）

- 用户目标：<要求和非目标>
- 范围：<允许写入的路径、禁止路径、协作模块>
- 已确认决策：<接口、平台、性能/正确性取舍>
- 需要主 Agent 决策：<尚未授权的接口或范围变动>
- 验收标准：<可观测行为与要求的证据>

## 加载清单（SubAgent）

- 公共入口：`AGENTS.md`
- 专属 Skill：<工作区相对路径>
- 实施参考：<仅相关章节，避免加载整套历史>
- 源码证据：<文件与符号；行号注明快照>

## 本次工作包（SubAgent）

- 实施步骤：<单次可交付范围，不粘贴全部路线图>
- 回归场景：<正常、边界、失败、并发>
- 验证要求：<工具/配置/预期行为；没有环境明确报告阻塞>
- 风险与约束：<用户修改、ABI、所有权、线程安全>
- 禁止事项：<不重构无关代码、不提交、不扩大范围>

## 结果（SubAgent 回填）

- 状态：<完成/部分完成/阻塞>
- 修改文件：<简表>
- 公共接口变化：<无或明确列出>
- 已执行验证：<实际命令、结果、配置；不写拟执行命令充当证据>
- 未验证事项：<原因及影响>
- 剩余风险：<具体项>

## 验收（主 Agent 回填）

- 范围与用户要求：<通过/需返工>
- 证据复核：<通过/缺证据>
- 后续委派：<无或下一工作包>
